# Engineering status

The 0.1 engineering line has completed its bounded native architecture proof:
package lifecycle and retained data, scoped permissions, App/Shell recovery,
diagnostics, provider replacement and health-gated System recovery.

This publication snapshot has a different file set and source identity. Its own
build/test receipts must identify the exact candidate and must not inherit a PASS
by copying an older status label. See [source identity](../../SOURCE_IDENTITY.md),
[preview limits](../release/0.1-preview.md) and the [quickstart](../development/QUICKSTART.md).

Networking, sustained interactive use and one physical reference target are
planned next-stage work. An official signed release and ordinary-user readiness
remain separate decisions and evidence requirements.
