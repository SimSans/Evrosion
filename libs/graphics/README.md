# Software graphics core

Safe no_std/no-allocation raster drawing, a strict versioned surface header and
scalar Present request/release frames. Semantic Hello controls are independent
of pixel coordinates. This library grants no memory, device or input authority.
Hardware services retain the actual mapping/credit boundaries.

See [ADR-0046](../../architecture/adr/ADR-0046-owned-surfaces-and-userspace-display.md).
