# Security reporting

Evrosion is an early developer preview. Its bounded capability, isolation and
recovery proofs do not certify production hardware, authentication or a Stable
security boundary. See [scope and limits](docs/release/0.1-preview.md).

## Private reporting

Once this source snapshot is hosted, use [Security → Report a vulnerability](https://github.com/SimSans/Evrosion/security)
to send a private report. The publication procedure enables and verifies GitHub
Private Vulnerability Reporting before uploading source. This local file does
not establish that the hosted feature has already been enabled or tested.

If the private reporting form is unavailable, do not put vulnerability details,
credentials, personal data or unreviewed diagnostic archives in a public issue.
Wait for a verified private route rather than publishing sensitive details.

Include the tested source/build, affected component, expected and actual
behavior, a minimal reproduction and unmodified relevant logs. Identify the
trust or capability boundary crossed.

Use systems and data you own or have permission to test. Minimize access if
unrelated sensitive data appears. Do not disrupt third parties or use social
engineering. No bounty, response deadline or special legal agreement is promised
by this file.
